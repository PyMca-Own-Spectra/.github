## Inside PyMca

PyMca is a local Windows spectroscopy app with a named pymca desk, a short scan list, and a clear last handoff. It does not try to replace the rest of the PC. It sits beside spectra you already keep and holds only the scan that is open now.
The layout stays small on purpose: one desk, one list, one path back. Extra scans wait for their own title. PyMca starts with a local profile and does not need a complex account system.

The pymca desk stays on files you already own. Untitled scans stay off the live list.

## Quick Start with PyMca

1. Open the last PyMca session on spectra you keep, not a new empty scan.
2. Read the pymca desk and the last handoff.
3. Finish one visible fit view inside PyMca.
4. Write what changed, then close with a shorter scan list than you found.
5. If the desk feels crowded, drop anything that belongs to a different file.
6. Leave the pymca desk on spectra you already own.
